## 🚀 Установка

### Системные требования
| | Минимальные | Рекомендуемые |
|:-|:------------|:--------------|
| **ОС** | Windows 10 | Windows 11 |
| **Процессор** | Intel i5-6600K | Intel i7-9700K |
| **Память** | 8 GB RAM | 16 GB RAM |
| **Видеокарта** | GTX 1060 | RTX 3060 |
| **Интернет** | 10 Mbps | 50 Mbps |
| **Место на диске** | 15 GB | 20 GB |

### Скачивание
1. Перейдите в раздел [Releases](https://github.com/yourusername/Z.E.R.O/releases)
2. Скачайте клиент и лаунчер
3. Установите через `ZERO_Launcher.exe`
4. Зарегистрируйте аккаунт или войдите
5. Выберите сервер и присоединяйтесь!
